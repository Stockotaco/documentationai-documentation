## Welcome

Bridge is a local web UI for the pi coding agent. You use it to run several agent threads side by side, keep work organized by project, and move between tasks without losing context. It is a starter kit page, so you can adapt the wording, structure, and links to match your own product.

## How the thread model works

Bridge organizes work around threads. Each thread behaves like its own agent session, so you can keep parallel tasks separated while still managing them from one interface. That makes it easier for you to review progress, steer a task mid-run, or branch into a new path when a different approach is worth trying.

The model is useful when you want clear ownership for each task, predictable context, and a visible history of what happened next. It also supports a shared loadout, so the same core capabilities are available wherever you open the tool.
